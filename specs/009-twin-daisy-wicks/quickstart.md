# Quickstart: Twin Wick and Daisy Wick in game

On flatworld, with the new jar on client and server.

1. **Twin alongside**: a Hookah and four Snip Stations in a row, facing every which way, with one line of Hemp Twin Wick beside them. Each reads about 105 W.
2. **Twin inline**: Hookah, cable, machine, cable, machine, cable, machine. Same readings.
3. **Daisy LED string**: a Double Hose and ten Lit Bits with a Rolled Daisy Wick through them, a Weedweeno in range running Rainbow. Each lamp reads about 4.2 Kb and lights. Break one lamp where the cable ends at it: the whole string goes dark, and the Inspoweedometer says the loop is open.
4. **Daisy branch**: add a cable sticking off the side of the line. The string goes dark, and the meter says it can't branch. Remove it and the string comes back.
5. **Rails**: run a red and a black single Wick from an existing rail to a Twin line; its machines run. Feed a Daisy line from a red Wick at one end and a black Wick at the other.
6. **Burnout**: a Hemp Twin Wick on a Double Hose burns in smoke and ash; nothing explodes.
7. **Looks**: straight runs, corners, a Twin T-junction, forks into blocks, glow while live, dyed sheaths.
