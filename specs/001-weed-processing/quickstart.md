# Quickstart: In-Game Checks

Run on the local test server (`C:\Users\Ignus\mc-local-server`) with the same jar on the client.

## Stage 1

1. Harvest a mature crop: rough buds and a seed, no cured buds.
2. Right-click a Trim Tray: one trimmed bud, sometimes a seed.
3. Load a Curing Rack: buds show on the rack and cure in 5 minutes.
4. Roll and smoke a joint. Try to smoke a rough bud: refused.

## Stages 2-4

1. Lit Hookah → Hemp Wick → Stash Jar → Terpinator, sober: it runs.
2. Unplug it and smoke within 21 blocks: it runs free.
3. Wait for the high to end: it pauses at the same progress.
4. Repeat free running after a bong hit and after an edible.
5. Run a Big Bertha through a Hemp Wick into a Rip block: smoke and ash. Feed a Puff machine from a Stash Box: it overloads, screen green and smoky, nothing breaks.
6. Catch a colour at an Infuser sober with no power: refused, pool kept.

## Stage 5

1. Hopper → Snip Station → hopper → Dry Box → chest, on power, player away and sober.
2. Feed two strains: both come out unchanged.
3. Compare each tier's speed.
