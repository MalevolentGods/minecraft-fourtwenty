# Quickstart: checking the Handbook in game

Local test server (`C:\Users\Ignus\mc-local-server`), a fresh survival character.

## M1 The book
1. Craft the Handbook (book + weed bud). Use it: cover art, then DON'T PANIC alone on the next page, then the title page and contents.
2. Click Getting Started → Your First Grow; follow a link; press back; close and reopen (bookmark).
3. Hover an item picture (tooltip); check a recipe picture matches the crafting table.
4. Follow Getting Started and Growing Weed from four seeds to a smoked joint.

## M2 All chapters
1. Open every entry from the contents; click every link once (the build check already proved they resolve).
2. Without MineColonies (standalone run): no Colony Life chapter, no colony links or index lines.
3. With an undiscovered terpene: its name never appears; discover it and reopen: it does.

## M3 Inspoweednetics
1. Build each of the six example circuits from its steps only; each behaves as the book says.
2. Translation table lists every electronic part; units table present.

## M4 Ranks and Stoner Badges
1. New character: Tenderbud requirements tick as you plant, harvest, trim, cure and smoke (notice each time).
2. Sign an honour requirement; relog; still ticked. Die; still ticked.
3. Earn Tenderbud: notice, sound, emblem; chat line if the server setting is on.
4. `/fourtwenty handbook reset <you> all` clears it.

## M5 Stoner Badge Sash
1. Wear it (Curios body slot; and in the chest slot on a run without Curios): earned patches show.
2. Earn a badge while a second player watches: the patch appears for both.

## M6 PDF and release
1. `python tools/build_handbook_pdf.py` makes `docs/handbook/A-Handbook-of-Weedcraft.pdf`; cover, DON'T PANIC, clickable contents and index, check-off pages.
2. A fresh Supply Ship and Supply Camp each have a Handbook in their racks.
